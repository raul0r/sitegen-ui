# UX Copy

Tone: concise, technical, calm.

Prefer:

```text
Build failed
Astro exited with a non-zero status.
BUILD_FAILED
Request: 7f3...
```

Avoid playful error copy.

Use explicit status language:

- Queued
- Running
- Succeeded
- Failed
- Cancelled
- Not configured
- Unavailable
- Validated
- Preview ready

Button labels use verbs:

- Create Project
- Save Artifact
- Initialize Git
- Create Branch
- Create Checkpoint
- Run Build
- Run QA
- Publish GitHub
- Push Branch
- Deploy Preview
- Refresh Deployment
- Run Live QA
- Open Preview

Explain disabled dependencies, e.g.:

`Publish this project to GitHub before creating a Cloudflare preview.`
